# 布局：不遮挡、不出画

## 先排全景图

1. 先在纸上（或脑子里）定主线方向。等距视角下：
   - `+x` 往屏幕**右下**，`+y` 往屏幕**右上**。
   - 一条横向主线：让 `x + y` 递增，`x − y` 不变（比如 `(0,0) → (6,6) → (12,12)`），屏幕上是水平向右。
   - 也可以沿单一轴走：沿 `+y` 是往右上的斜线，沿 `+x` 是往右下的斜线。
2. 相邻节点间隔 8–12 格。小于 6 格，标签和连线文字就挤在一起。
3. 分组用 `zone`，区域之间留 2 格空隙。
4. 同一个点的分支（比如订单服务同时连库存、支付、订单库）往不同方向发散：一个往右上、一个往右下、一个往左下。不要两个都往右上。

## 常见遮挡和改法

| 现象 | 改法 |
| --- | --- |
| 连线文字压在体块上 | 先看能不能删掉（和标签重复的连线文字最先删），再调 `labelAt`，最后挪节点 |
| 两条连线的文字挤在一起 | 两个终点离得太近，挪开其中一个；或者其中一条 `label: ''` |
| 头顶标签压住后面的体块 | `pills: 'below'` 把标签放到下方；或把后面的体块挪远 |
| `db` 名字被连线穿过 | `db` 名字在圆柱正下方，别让连线从它下方出去：上游放在它的左下 / 左上 |
| 高体块挡住后面的东西 | 高的放在屏幕下方（`x − y` 大的一侧），或把 `h` 压矮 |
| 信息卡盖住画面 | 默认会自动选角；还是压到时固定 `corner: 'bl'` 等，或用 `camera` 留出空角 |
| 柱子比高度时看着不准 | 柱子放在同一条屏幕水平线上（`x − y` 相同，如 `(-3.5,-3.5)` 和 `(3.5,3.5)`） |
| 封面文字压住图 | split 封面用 `camera.at` 把图推到右边：`at` 取在图的左下方 |

## shoot 报告怎么看

`shoot` 在每一页、每一拍截图，并用页面上元素的真实位置检查：

- **✗ 遮挡**：文字（连线文字、标签、信息卡、便签、封面）和别的元素重叠 15% 以上。必须修。
- **! 提醒**：轻微重叠（6–15%），体块之间重叠，或元素超出画面。逐条看图判断。
- 体块和文字比较时只算体块中间那块，四个空角不算，所以文字落在六边形旁边不会误报。
- 节拍推近时，变暗的元素出画不报。没变暗的出画，说明镜头没对准，或这一页的 `camera` 本来就裁掉了一部分（这时可以忽略）。

报告查不出的问题，只能看图：

- 正在讲的那块是不是在画面中间、够不够大？
- 一页里新出现的东西是不是太多？
- 箭头方向对不对（谁调用谁）？
- 颜色有没有意义：同一类东西同一个颜色，坏了的红色，新加的绿色。

改完一处就重新 `shoot --steps <页>`，只截那几页，几秒钟就能看到结果。
